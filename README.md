# Org Chart Viewer (local run)

This project wraps your `OrgChartViewer.jsx` into a small Vite React app so you can run it locally.

Prerequisites
- Node.js 16+ (recommended 18+)

Quick start

```bash
# from project root
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

Notes
- `OrgChartViewer.jsx` is expected at the project root (it already exists).
- If your browser blocks clipboard or other features in a sandbox, those parts may be no-op.
